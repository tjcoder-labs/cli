# Welcome to @tjcoder/cli

**by TJ Coder | AI Labs SLC**

You're now running a keyboard-driven, terminal-native AI coding assistant with real tools, a live cognition pane, and persistent memory across sessions.

To get the most out of the CLI, pick the agent that best matches what you want to do. You can switch agents any time with `/agent`.

---

## Available Agents

### software-engineer
The default. Full-stack development from the terminal: reads code, edits files, runs tests, drives the browser via CDP, manages tasks, and presents changes on the canvas pane. Best for day-to-day coding work.

### terminal-specialist
Focused on shell workflows, debugging, build systems, and CLI ergonomics. Use when you want a lighter-weight assistant for ops-style tasks.

### code-reviewer
Read-only review of diffs, PRs, and files. Won't write to your tree. Use when you want a second pair of eyes on a change before you ship.

### android-assistant
Android development with ADB access. Inspect devices, pull logs, install APKs, and reason about Android-specific issues.

### cloud-expert
Cloud infrastructure: DNS via Cloudflare, deploys, config drift, provider comparisons. Use when the work is more "infra" than "code".

### social-researcher
Long-form research on social platforms: scrapes threads, profiles, and conversations, and saves structured notes for later citation. Browser-heavy.

### storyteller
Creative writing partner. Outlines, drafts, and revises prose without touching your codebase. Good for docs, blog posts, and narrative work.

---

**Pick one to get started.** You can switch at any time with `/agent <slug>` or `/agent` to reopen the picker.
